Imports

Sport80 membership export

Export the referee membership list from Sport80 as CSV. The importer matches on email (then on first and last name) and updates the membership validity date and member ID. Expected columns, any order, header names flexible: email, first name, last name, member id, expiry or valid until. Unmatched rows are listed for review and nothing is created automatically.

IHF Catalogue of Rules Questions

Paste the text of the IHF catalogue (questions file) and, separately, the answers file. The parser recognizes the numbering 7.12) with options a) to d), assigns the rule number from the question number, and marks the correct options from the answers file. Review in the Questions tab afterwards; everything imports as Level 2 by default.
